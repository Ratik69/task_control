# Task Control

Веб-приложение для контроля задач в ресторане. Менеджеры создают задачи
и шаблоны, сотрудники выполняют их и прикладывают фото, менеджеры
принимают или отклоняют результат.

## Возможности

- Роли: сотрудник, менеджер, управляющий, администратор
- Разовые и ежедневные задачи, шаблоны с временем появления и сроком
- Отправка выполнения с фото и комментарием
- Проверка менеджером: принять или отклонить
- История и список предстоящих задач
- Управление сотрудниками (добавление, отключение, смена пароля)
- Установка на телефон как PWA

## Технологии

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Supabase
(авторизация, база данных, хранилище фото).
